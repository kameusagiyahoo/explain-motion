# Roadmap

## Phase 1 — Text → Explanation Video

Complete in this MVP: text planning, schema validation, normalization, seven scene types, Remocn/Remotion rendering, Player, Storyboard, editing, and local MP4 output.

## Phase 2 — URL → Video

Fetch and safely extract selected web content, retain citations, and transform the semantic model into the same VideoPlan.

## Phase 3 — PDF → Video

Extract pages, headings, figures, and source references; add document-aware explanation planning.

## Phase 4 — CSV / Data → Video

Add typed datasets, chart analysis, and ChartScene variants with deterministic axes and labels.

## Phase 5 — GitHub → Video

Explain repository architecture, history, pull requests, and diffs through specialized analyzers and existing/generalized diagram scenes.

## Phase 6 — Voice

Add TTS, captions, timing reconciliation, and optional BGM while preserving deterministic renders.

## Phase 7 — Universal Explanation Engine

```text
Content → Semantic Model → VideoPlan → Video
```

All source formats converge at the same versioned contract, allowing analyzers and renderers to evolve independently.
